# 映画ドラマ手帖 — セットアップ手順

`index.html` 1ファイルだけで動く静的サイトです。費用はかかりません。アニメ手帖と同じ作りです。

## 1. 公開する（GitHub Pages）
1. GitHub で新しい空のリポジトリを作る（例: `eiga-drama-techo`、Public）
2. `index.html` と `README.md` を置く（Claudeが push します）
3. Settings → Pages → Source を `Deploy from a branch`、Branch を `main` / `(root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## 2. TMDBキー（必須）
ドラマ一覧・映画検索・配信バッジはすべて TMDB から取得します。アニメ手帖と同じキーが使えます。
- 設定タブに貼って保存。Drive連携すると別端末にも引き継がれます（評価データのJSONには入りません）。
- アニメ手帖でDrive連携済みなら、初回連携時にそのキーを自動で引き継ぎます。

## 3. Google Drive に自動保存する
アニメ手帖と同じ OAuth クライアントIDを埋め込み済みです。追加で必要なのは1つだけ。
- Google Cloud → 認証情報 → 該当のOAuthクライアント → **承認済みのリダイレクトURI** に
  `https://<ユーザー名>.github.io/<リポジトリ名>/` を追加
- サイトの設定タブ →「連携 / 今すぐ同期」。以後、評価を保存するたびに `eiga-drama-db.json` へ自動保存。
- テストモードのため約7日ごとに「☁ 要再接続」をクリックして再接続が必要です。

## 使い方
- **ドラマ**: 年・クールを選ぶと日本のドラマが並びます。TMDBに無い作品は検索 → 「手動で追加」。初回放送が昔の続編（相棒など）は「続編・継続作品も含む」を ON。
- **映画**: 何も表示されません。タイトルを検索して「☆ 気になる」で観たい映画をメモ。「Prime/Netflixで見放題」で絞ると、今すぐ観られるものだけ出ます。観たら点数と一言メモ。
- 評価の目安: 7=完走 / 8=面白い / 9=かなり面白い / 10=神 / 切った=4

## データ形式（eiga-drama-db.json）
`ratings` のキーは `tv:<TMDB ID>`（ドラマ）、`mv:<TMDB ID>`（映画）、手動追加は `tv:m…` / `mv:m…`。
先頭の `_readme` に項目の説明が入っており、そのまま他のAIに渡して分析できます。削除は `deleted: true`、競合は `updated_at` が新しい方を採用します。

## 注意
- 配信データは JustWatch（TMDB経由）です。ずれていたら作品を開いて手動で上書きできます。
- 個人利用（非商用）の範囲で使ってください（TMDB規約）。
